= Multi-Lingua Reader

This is a **purely vibed** test in an attempt to mimic the [Scaife Viewer](https://scaife.perseus.org) for multiple languages.

Till now only Chinese interface is supported.

A lot of online sources are used in this project, including, but not limitted to Glottolog, Unicode CLDR, Wiktionary/Wiktextract, Universal Dependencies, UniMorph, PanLex, Open Multilingual Wordnet, FreeDict, OPUS, Grambank, WALS, PHOIBLE, CLTS, Concepticon, Lexibank, CLICS, DoReCo, Wikimedia Commons, Lingua Libre, Forvo and Mozilla Common Voice. The full source list could be found on page.

== To start:

```bash
npm install
npm run build
npm run start
```

... or simply use

```bash
npm install
npm run dev
```

to start on dev mode.
